# 📱 Mobile Testing Guide & Quick Reference\n\n## Quick Testing Checklist\n\n### 1. Manual Device Testing\n`bash\n# Test on these phones (if available):\n- iPhone SE (375px width) - smallest modern iPhone\n- iPhone 14 (390px width) - standard iPhone\n- Pixel 6/7 (412px width) - Android standard\n- Galaxy Fold (280px/408px width) - foldable edge case\n\n# Test on these tablets:\n- iPad Air (768px width) - standard tablet\n- iPad Pro (1024px width) - large tablet\n\n# Test orientations:\n- Portrait (normal)\n- Landscape (rotated)\n`\n\n### 2. Chrome DevTools Testing (Quick)\n`\n1. Open DevTools: F12 or Cmd+Option+I\n2. Click device toolbar icon (Ctrl+Shift+M)\n3. Select device from dropdown:\n   - iPhone SE: 375x667\n   - iPhone 14: 390x844\n   - Pixel 6: 412x915\n   - iPad Air: 768x1024\n4. Enable throttling: Network → Slow 3G\n5. Check Performance tab:\n   - FPS should stay 60fps\n   - No jank during animations\n`\n\n### 3. Form Input Testing\n`\n📝 On Mobile Device:\n- Tap email field → Should show email keyboard (@, .)\n- Tap phone field → Should show numeric keyboard\n- Tap name field → Should show text keyboard\n- Submit button should be easy to tap (44x44dp+)\n`\n\n### 4. Animation Testing\n`\n✨ Galaxy Background:\n- Desktop: Smooth, no stuttering (density: 0.6)\n- Mobile: Lighter animation (density: 0.4)\n- Low-end (1GB RAM): Very light (density: 0.3)\n\n✨ ScrollAction:\n- Hero: Icon cloud should be smooth on drag\n- Projects: Marquee should scroll smoothly\n- No horizontal scroll overflow\n`\n\n### 5. Touch Targets\n`\n🎯 Tap these and verify 44x44dp minimum:\n- Mobile menu hamburger button\n- Contact form submit button\n- All form inputs\n- Navigation links\n\nIf hard to tap on small phone → FAIL\nIf easy to tap (44x44+) → PASS\n`\n\n---\n\n## DevTools Performance Profiling\n\n### Check Frame Rate (60fps Target)\n`\n1. Open DevTools → Performance tab\n2. Click record button (circle)\n3. Interact with animations (scroll, open menu, 3D cloud)\n4. Stop recording\n5. Look at FPS counter:\n   - Green = 60fps ✅\n   - Red dips = 30fps ⚠️\n`\n\n### Check Memory Usage\n`\n1. Open DevTools → Performance → Memory\n2. Take heap snapshot\n3. Check memory usage:\n   - Desktop: < 50MB baseline\n   - Mobile: < 30MB baseline\n   - Low-end: Should not spike above 100MB\n`\n\n### Network Performance\n`\n1. DevTools → Network tab\n2. Set throttling to \"Slow 3G\"\n3. Reload page\n4. Verify load time < 5 seconds\n5. Check lazy image loading (50px margin)\n`\n\n---\n\n## Lighthouse Audit\n\n### Run Lighthouse\n`\n1. DevTools → Lighthouse tab\n2. Select \"Mobile\"\n3. Uncheck all except \"Performance\"\n4. Click \"Analyze page load\"\n`\n\n### Acceptable Scores\n`\nScores:\n- Performance: ≥ 85% (target: 90%+)\n- FCP (First Contentful Paint): < 1.8s\n- LCP (Largest Contentful Paint): < 2.5s\n- CLS (Cumulative Layout Shift): < 0.1\n`\n\n---\n\n## Real Device Testing (Recommended)\n\n### Using macOS (iPhone)\n`bash\n# Connect iPhone via USB\n# Safari → Preferences → Advanced → \"Show Web Inspector menu\"\n# On iPhone: Settings → Safari → Advanced → Web Inspector ON\n# Safari → Develop → [iPhone] → Choose site\n`\n\n### Using Android\n`bash\n# Enable Developer Mode:\n# Settings → About Phone → Tap \"Build Number\" 7 times\n# Settings → Developer Options → Enable USB Debugging\n\n# Chrome Remote Debugging:\n# chrome://inspect → Check \"Discover USB devices\"\n# Connect device → Inspect\n`\n\n---\n\n## Specific Test Cases\n\n### Test Case 1: Form Submission on Mobile\n`\nSteps:\n1. keyboard not showing\n`\nSolution:\n- Verify inputMode=\"email\" is present\n- Try refreshing page\n- Test on different device\n- Check browser version (older Safari may not support)\n`\n\n### Issue: Laggy animations on mobile\n`\nSolution:\n- Check device capabilities: useDeviceDetection should detect\n- Open DevTools Performance tab\n- Check if GPU acceleration is enabled\n- Try disabling browser extensions\n- Test on different device\n`\n\n### Issue: Buttons hard to tap\n`\nSolution:\n- Verify min-h-[44px] and min-w-[44px] CSS\n- Check DevTools zoom level (should be 100%)\n- Test with actual finger (not mouse)\n- Measure button size: should be ≥ 44x44dp\n`\n\n### Issue: Horizontal scroll overflow\n`\nSolution:\n- Check Marquee component width\n- Use DevTools to inspect element\n- Verify overflow-x: hidden is set\n- Test in landscape mode\n`\n\n---\n\n## Automated Testing Commands\n\n`bash\n# Build for production\nnpm run build\n\n# Preview production build\nnpm run
